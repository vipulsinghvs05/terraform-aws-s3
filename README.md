# Terraform AWS S3

This project provisions a secure Amazon S3 bucket using Terraform.

## Features

- Creates an S3 bucket
- Enables Versioning
- Enables Server-Side Encryption (SSE-S3)
- Blocks Public Access
- Uses variables for configuration
- Outputs bucket name and ARN

## Prerequisites

- Terraform
- AWS CLI configured
- AWS Account

## Files

- provider.tf
- versions.tf
- variables.tf
- terraform.tfvars.example
- main.tf
- outputs.tf

## Usage

- terraform init
- terraform plan
- terraform apply
- terraform destroy
